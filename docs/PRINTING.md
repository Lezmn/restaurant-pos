# พิมพ์ใบเสร็จด้วยเครื่องพิมพ์ความร้อน (USB)

ระบบพิมพ์ผ่านเบราว์เซอร์ (`window.print()`) — ไม่ต้องลงโปรแกรมเพิ่มนอกจาก driver ของเครื่องพิมพ์
ตั้งค่าตามนี้แล้วกดรับเงินเสร็จ ใบเสร็จออกทันทีโดยไม่มีหน้าต่างถามก่อนพิมพ์

ใช้ได้กับเครื่องพิมพ์ใบเสร็จ 80 มม. หรือ 58 มม. ทั่วไป (Xprinter, Gprinter, Epson TM ฯลฯ)
ต่อ USB กับ **คอม/โน้ตบุ๊ก Windows ที่เคาน์เตอร์** — แท็บเล็ตใช้วิธีนี้ไม่ได้

## 1. ติดตั้งเครื่องพิมพ์ใน Windows (ครั้งเดียว)

1. ลง driver จากเว็บผู้ผลิตหรือแผ่นที่มากับเครื่อง → เสียบ USB → พิมพ์หน้าทดสอบจาก Windows ให้ออกก่อน
2. **Settings → Bluetooth & devices → Printers & scanners**
   - ปิด "Let Windows manage my default printer"
   - เลือกเครื่องพิมพ์ใบเสร็จ → **Set as default**
3. **Printing preferences** ของเครื่องพิมพ์ใบเสร็จ:
   - Paper size: `80mm x Receipt` (หรือ 72mm / 58mm ตามรุ่น) — **ห้ามเป็น A4/Letter** ไม่งั้นพิมพ์ยาวเป็นหน้า
   - ถ้ามีตัวเลือก "Cut" / "Paper cut" → ตัดกระดาษหลังพิมพ์ (cut at end of document)

## 2. ทางลัด Chrome สำหรับเคาน์เตอร์

สร้างทางลัดบน Desktop (คลิกขวา → New → Shortcut) ใส่ช่อง location:

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --user-data-dir="C:\pos-chrome" https://APP_DOMAIN/employee/check
```

- `--kiosk-printing` = สั่งพิมพ์แล้วออกเครื่องพิมพ์หลัก (default) ทันที ไม่เปิดหน้าตั้งค่าการพิมพ์
- `--user-data-dir` = แยกโปรไฟล์ไว้ใช้กับ POS อย่างเดียว — flag จะมีผลก็ต่อเมื่อ Chrome โปรไฟล์นี้ยังไม่ได้เปิดค้างอยู่
  (ถ้าเปิด Chrome ปกติไว้แล้วกดทางลัดนี้ flag ก็ยังทำงาน เพราะเป็นคนละโปรไฟล์)
- เปลี่ยน `APP_DOMAIN` เป็นโดเมนจริงของร้าน (ค่าเดียวกับใน `.env` ตอน deploy)
- ใช้ **ทางลัดนี้ทางเดียว** ในการเปิดระบบที่เคาน์เตอร์ — เปิด Chrome ธรรมดาจะกลับไปมีหน้าต่างถามก่อนพิมพ์

ครั้งแรกที่เปิดทางลัด: login ด้วยบัญชีหน้าร้าน แล้วลองพิมพ์ใบเสร็จจากหน้า Check (บิลที่ชำระแล้ว → ใบเสร็จ → พิมพ์)
ถ้าขอบซ้าย/ขวาโดนตัด ให้ปรับ margin ใน Printing preferences ของ driver ก่อน

## 3. เปิด "พิมพ์ใบเสร็จทันทีหลังรับเงิน"

ในหน้าใบเสร็จ (เปิดจากบิลไหนก็ได้) ติ๊ก **พิมพ์ใบเสร็จทันทีหลังรับเงิน**

- เป็นค่าของ **เครื่องนี้เท่านั้น** (เก็บในเบราว์เซอร์) — เปิดที่คอมเคาน์เตอร์ แท็บเล็ตหน้าร้านไม่ต้องเปิด
  ไม่งั้นแท็บเล็ตจะเด้งหน้าต่างพิมพ์ทุกครั้งที่รับเงิน
- พิมพ์อัตโนมัติเฉพาะตอน **เพิ่งรับเงินเสร็จ** — เปิดดูใบเสร็จย้อนหลังไม่พิมพ์เอง (กดปุ่ม "พิมพ์ใบเสร็จ" ถ้าต้องการพิมพ์ซ้ำ)
- ล้างข้อมูลเบราว์เซอร์ / ใช้โปรไฟล์ใหม่ ต้องติ๊กใหม่

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ยังมีหน้าต่างถามก่อนพิมพ์ | ไม่ได้เปิดผ่านทางลัดที่มี `--kiosk-printing` — ปิด Chrome โปรไฟล์ POS ทุกหน้าต่างแล้วเปิดใหม่จากทางลัด |
| ไปออกเครื่องพิมพ์อื่น / ออกเป็น PDF | เครื่องพิมพ์ใบเสร็จไม่ได้เป็น default ของ Windows (ข้อ 1.2) |
| กระดาษยาวเกิน / มีหน้าเปล่าต่อท้าย | Paper size ใน driver เป็น A4 — เปลี่ยนเป็นขนาดใบเสร็จ (ข้อ 1.3) |
| ตัวหนังสือจาง | เปลี่ยนความเข้ม (Density/Darkness) ใน driver หรือเปลี่ยนกระดาษความร้อน — ระบบพิมพ์สีดำล้วนอยู่แล้ว |
| ติ๊กแล้วแต่ไม่พิมพ์เอง | ติ๊กคนละเครื่อง/คนละโปรไฟล์ — ติ๊กในหน้าต่างที่เปิดจากทางลัด |
| เครื่องพิมพ์เสีย/กระดาษหมดกลางกะ | รับเงินได้ตามปกติ ใบเสร็จเก็บในระบบ — พิมพ์ย้อนหลังจาก "บิลที่ชำระแล้ว" ในหน้า Check ได้ |
